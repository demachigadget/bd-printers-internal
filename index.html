このツールについて

BD Bambu Share v1.0 — BASSDRUM 専用 Bambu Lab プリンタ共有見える化システム

実装機能:

  • 📊 5台のプリンタ状態をリアルタイム自動表示（温度・進捗・終了予定時刻）
  • 🟡「使用中」マークでメンバー間の共有
  • 📅 予約カレンダー（重複防止）
  • 🔧 メンテナンス記録（種別・履歴管理）
  • 💬 連絡帳（フィラメント残少などをカテゴリ別投稿）
  • 🔐 Bambu Studio 初回ログインの2FAコード自動配布（共有Gmail監視）
  • ⚠️ 印刷終了後の「回収待ち」警告（プレートが片付いていない時、次の印刷を防ぐ）

オフィス: 乃木坂（2台）／ 京都（3台）

構成: GitHub Pages（UI） + Google Apps Script + スプレッドシート（DB） + fly.io（MQTT 中継）
